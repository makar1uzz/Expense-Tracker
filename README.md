## 📖 О программе

**Expense Tracker** — это простое и удобное приложение с графическим интерфейсом для отслеживания личных финансов. Программа помогает контролировать расходы, анализировать траты по категориям и периодам.

### ✨ Основные возможности

- ✅ **Добавление расходов** — быстрый ввод суммы, категории и даты
- 🔍 **Фильтрация** — по категориям и диапазону дат
- 📊 **Подсчёт суммы** — автоматический расчет расходов за выбранный период
- 💾 **Сохранение данных** — автоматическое сохранение в JSON-файл
- 🗑️ **Удаление записей** — удаление ненужных расходов из истории
- ✔️ **Валидация ввода** — проверка корректности суммы и формата даты

### 🗂️ Категории расходов

- Еда
- Транспорт
- Развлечения
- Здоровье
- Счета
- Другое

Сохраните файл `main.py` в любую папку на вашем компьютере.

## 📱 Как пользоваться

### 1️⃣ Добавление расхода

| Поле | Описание | Пример |
|------|----------|--------|
| **Сумма** | Положительное число | `500.50` |
| **Категория** | Выберите из списка | `Еда` |
| **Дата** | Формат ГГГГ-ММ-ДД | `2025-03-20` |

1. Заполните все поля
2. Нажмите кнопку **"Добавить расход"**
3. Расход появится в таблице

### 2️⃣ Фильтрация расходов

#### По категории
- Выберите нужную категорию в выпадающем списке
- Таблица автоматически обновится

#### По дате
- Укажите начальную дату в поле **"Дата от"**
- Укажите конечную дату в поле **"до"**
- Нажмите **"Применить фильтр"**

#### Сброс фильтров
- Нажмите кнопку **"Сбросить фильтры"**

### 3️⃣ Просмотр общей суммы

Программа автоматически подсчитывает сумму всех расходов, отображаемых в таблице (с учётом применённых фильтров).

### 4️⃣ Удаление расхода

1. Выделите строку с расходом в таблице (кликните по ней)
2. Нажмите кнопку **"Удалить выбранный расход"**
3. Запись будет удалена

## 📝 Примеры использования

### Пример 1: Ежедневные расходы

**Ситуация:** Вы хотите записать расходы за день.

1. Добавьте **500 руб.** (Еда, 2025-03-20)
2. Добавьте **200 руб.** (Транспорт, 2025-03-20)
3. Добавьте **150 руб.** (Развлечения, 2025-03-20)

**Результат:** Общая сумма за 20 марта = 850 руб.

### Пример 2: Анализ расходов за неделю

**Ситуация:** Вы хотите узнать, сколько потратили на еду за последнюю неделю.

1. Установите фильтр **"Дата от"** = начало недели (например, 2025-03-14)
2. Установите фильтр **"до"** = конец недели (2025-03-20)
3. Выберите категорию **"Еда"**

**Результат:** Таблица покажет только расходы на еду за указанный период и их общую сумму.

### Пример 3: Месячный отчёт

**Ситуация:** Нужен отчёт о всех расходах за март 2025.

1. Установите **"Дата от"** = 2025-03-01
2. Установите **"до"** = 2025-03-31
3. Выберите категорию **"Все"**

**Результат:** Все расходы за март и их общая сумма.

## ⚠️ Возможные ошибки и их решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Не удалось загрузить данные` | Повреждён файл `expenses.json` | Удалите файл и перезапустите программу |
| `Сумма должна быть числом` | В поле суммы введены буквы | Введите число (например, 500) |
| `Неверный формат даты` | Дата введена неправильно | Используйте формат ГГГГ-ММ-ДД (например, 2025-03-20) |
